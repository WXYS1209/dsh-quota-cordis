# Bundled company and product brand marks

The supplemental geometry in [company-brand-marks.json](<../src/data/company-brand-marks.json>) is copied from the pinned, redistribution-licensed sources below. It is rendered locally as plain SVG paths; source and brand URLs are provenance metadata, never runtime image sources. No original third-party logo was invented for this feature.

All marks in this supplemental file are monochrome: the renderer supplies the current theme's foreground color. Original path geometry is retained, with whitespace normalized. Where the upstream SVG specifies an even-odd fill rule, `fillRule: "evenodd"` is retained. No scripts, styles, event handlers, remote references, embedded images, masks, clipping definitions or transforms are copied into the data.

### Pi adaptation

The Pi favicon contains a black rounded-square background and two white glyph paths. Only the two original glyph paths are retained, with their even-odd semantics; the decorative background rectangle is omitted. The viewBox is cropped to `125 125 550 550` so the transparent glyph reads at the same optical size as the other 24-pixel marks. White fills become theme foreground through the renderer. No glyph geometry is redrawn.

### Existing marks

The seven company-rule marks already assigned to OpenAI, DeepSeek, Moonshot/Kimi, Anthropic, Google, MiniMax and Zhipu remain in the client. The new file supplements the 22 previously missing assignments. Together these identify all 29 currently recorded company rules. A previously bundled OpenCode mark also exists; the supplemental file provides a pinned MIT source for that same product brand instead of asserting it is Anomaly's distinct corporate logo.

Unknown domains or future company rules without a bundled, licensed mark must continue to use the generic fallback; the presence of a mark never validates endpoint ownership or authorizes credentials.
